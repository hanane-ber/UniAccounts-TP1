# UniAccounts - TP 1: Design Patterns

## Description
Ce projet est un Travail Pratique (TP1) réalisé dans le cadre du module Design Patterns (Java). Il implémente un système de gestion des comptes étudiants en appliquant les trois patrons de conception créatifs : Builder, Singleton, et Prototype.

## Design Patterns Implémentés
1. Builder Pattern : Utilisé pour la construction flexible de la classe StudentAccount avec validation des attributs.
2. Singleton Pattern : Assure une instance unique pour AccountRepository et AuditLog.
3. Prototype Pattern : Permet de dupliquer rapidement des comptes de référence (templates) via un système de registre (AccountTemplateRegistry) avec Deep Copy.
